| Disciplina: Desenvolvimento Mobile (Flutter e Dart)                                                                                                                                                                                                                                                                   |                        |
| Tema: Formulários e Validações no Flutter                                                                                                                                                                                                                                                                             |                        |
|                                                                                                                                                                                                                                                                                                                       |                        |
|                                                                                                                                                                                                                                                                                                                       |                        |
| 1. Objetivo                                                                                                                                                                                                                                                                                                           |                        |
| Colocar em prática os conceitos vistos em aula, implementando uma tela completa de cadastro de usuário no Flutter. Nela, você vai capturar os dados digitados, aplicar filtros de entrada, validar cada campo e dar feedback visual ao usuário.                                                                       |                        |
|                                                                                                                                                                                                                                                                                                                       |                        |
| 2. Contexto                                                                                                                                                                                                                                                                                                           |                        |
| Todo aplicativo moderno precisa coletar informações do usuário, seja no cadastro, no login ou em uma compra. O formulário é a principal ponte entre o app e o usuário. Imagine que você foi contratado(a) para desenvolver a tela de cadastro de um novo aplicativo. Ela deve ser clara, segura e fácil de preencher. |                        |
|                                                                                                                                                                                                                                                                                                                       |                        |
| 3. Campos do formulário                                                                                                                                                                                                                                                                                               |                        |
| A tela deve conter os seguintes campos:                                                                                                                                                                                                                                                                               |                        |
|                                                                                                                                                                                                                                                                                                                       |                        |
| Campo                                                                                                                                                                                                                                                                                                                 | Observação             |
| Nome completo                                                                                                                                                                                                                                                                                                         | Texto livre            |
| E-mail                                                                                                                                                                                                                                                                                                                | Deve conter @          |
| CPF                                                                                                                                                                                                                                                                                                                   | Apenas números         |
| Telefone                                                                                                                                                                                                                                                                                                              | Apenas números         |
| Senha                                                                                                                                                                                                                                                                                                                 | Mínimo de 6 caracteres |
| 4. Regras de validação                                                                                                                                                                                                                                                                                                |                        |
| Todos os campos são obrigatórios.                                                                                                                                                                                                                                                                                     |                        |
| O e-mail deve conter o caractere @.                                                                                                                                                                                                                                                                                   |                        |
| A senha deve ter no mínimo 6 caracteres.                                                                                                                                                                                                                                                                              |                        |
| CPF e telefone devem aceitar somente números.                                                                                                                                                                                                                                                                         |                        |
| 5. Comportamento esperado                                                                                                                                                                                                                                                                                             |                        |
| O botão CADASTRAR aciona a validação do formulário.                                                                                                                                                                                                                                                                   |                        |
| Os erros são exibidos campo a campo, logo abaixo de cada campo inválido.                                                                                                                                                                                                                                              |                        |
| Quando todos os campos estiverem válidos, deve ser exibido um SnackBar de sucesso ao final do cadastro.                                                                                                                                                                                                               |                        |
| 6. O que deve ser implementado                                                                                                                                                                                                                                                                                        |                        |
| Criar a tela com os campos: nome, e-mail, CPF, telefone e senha, usando TextFormField dentro de um Form.                                                                                                                                                                                                              |                        |
| Permitir a digitação: configurar keyboardType e inputFormatters adequados para cada tipo de campo.                                                                                                                                                                                                                    |                        |
| Validar os campos: implementar validator com regras específicas para cada campo do formulário.                                                                                                                                                                                                                        |                        |
| Exibir mensagens de erro: garantir que os erros apareçam claramente abaixo de cada campo inválido.                                                                                                                                                                                                                    |                        |
| Exibir SnackBar de sucesso: mostrar uma mensagem de confirmação após o cadastro bem-sucedido.                                                                                                                                                                                                                         |                        |
| 7. Estrutura obrigatória da tela                                                                                                                                                                                                                                                                                      |                        |
| A hierarquia de widgets deve seguir esta estrutura:                                                                                                                                                                                                                                                                   |                        |
|                                                                                                                                                                                                                                                                                                                       |                        |
|                                                                                                                                                                                                                                                                                                                       |                        |
| Scaffold                                                                                                                                                                                                                                                                                                              |                        |
| └── Form(key: _formKey)                                                                                                                                                                                                                                                                                               |                        |
| └── SingleChildScrollView                                                                                                                                                                                                                                                                                             |                        |
| └── Column                                                                                                                                                                                                                                                                                                            |                        |
| ├── TextFormField (nome)                                                                                                                                                                                                                                                                                              |                        |
| ├── TextFormField (e-mail)                                                                                                                                                                                                                                                                                            |                        |
| ├── TextFormField (CPF)                                                                                                                                                                                                                                                                                               |                        |
| ├── TextFormField (telefone)                                                                                                                                                                                                                                                                                          |                        |
| ├── TextFormField (senha)                                                                                                                                                                                                                                                                                             |                        |
| └── ElevatedButton (CADASTRAR)                                                                                                                                                                                                                                                                                        |                        |
| Dicas importantes                                                                                                                                                                                                                                                                                                     |                        |
|                                                                                                                                                                                                                                                                                                                       |                        |
| SingleChildScrollView: envolva a Column para evitar overflow quando o teclado aparecer.                                                                                                                                                                                                                               |                        |
| Espaçamento: use SizedBox(height: 16) entre os campos para melhor legibilidade.                                                                                                                                                                                                                                       |                        |
| Padding: adicione Padding ao redor do formulário para ter margens laterais adequadas.                                                                                                                                                                                                                                 |                        |
| 8. Desafio                                                                                                                                                                                                                                                                                                            |                        |
| Quer ir além? Implemente também:                                                                                                                                                                                                                                                                                      |                        |

| Botão para mostrar/ocultar a senha.                                                                                                                                                                                                                                                                                   |                        |
| Validação de e-mail mais robusta com RegExp.                                                                                                                                                                                                                                                                          |                        |
